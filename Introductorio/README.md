# Curso Introductorio

#### Introducción

Material introductorio de Desarrollo Web Full Stack: fundamentos de JavaScript, HTML y CSS, más control de versiones con Git.

Es la base sobre la que se apoyan los módulos siguientes, así que conviene tener estos conceptos firmes antes de avanzar.

## ¿En qué consiste?

Cada unidad reúne material escrito, demos y ejercicios (`homework`) con sus tests. La idea es leer la lección, revisar las demos y después resolver los ejercicios verificando con los tests.

El material es asincrónico: se avanza al ritmo de cada quien, en el orden en que están numeradas las unidades.

## Contenido

| Unidad | Tema |
|---|---|
| 00 | Primeros pasos y herramientas |
| 01a–01c | Git, GitHub y conceptos base |
| 02–07 | JavaScript I a VI |
| 08 | HTML |
| 09 | CSS y posicionamiento |
| 10 | Ejercicios extra de JavaScript |
| 11 | Glosario |

## Cómo ejecutar los tests

Desde la carpeta donde está este `README.md`:

```bash
npm install
npm test
```

Para correr los tests de una unidad concreta, se le pasa la ruta a `npm test`.
